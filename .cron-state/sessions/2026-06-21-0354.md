## Notes / risks

- The named-attractors round-trip changes `setNamedAttractors` to
  drop entries that fail validation through `addNamedAttractorHelper`.
  This is safer than alternatives (mutating IDs, preserving garbage)
  but means a bookmark from a hypothetically-future schema that adds
  required fields would silently lose its attractors. Acceptable
  trade-off — bookmark schema additions should always default-fill.
- The "→ line N" jump button uses a rough line-height heuristic
  (`scrollHeight / lineCount`) to scroll the textarea. This works fine
  for fixed-width monospace fonts but could drift slightly with very
  long wrapped lines. The selection still lands correctly; only the
  scroll position is approximate.
- Spectrum log-frequency uses a base-10 curve (`10^(t)-1`/9). Base-2
  (octave-true) was considered but produces a steeper curve that
  squeezes the leftmost bars into ~1 bin each on a 64-bin spectrum,
  which looks visually worse. Base-10 is a softer compromise that
  still meaningfully redistributes vs. the linear bin-per-bar layout.
- Working directly on main from this tick onward (previous ticks used
  a feature/autoship branch that was merged back to main). The
  prompt's hard rules already said "work directly on main"; this tick
  is the first to actually do so end-to-end.
