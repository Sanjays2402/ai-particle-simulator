## Shipped

5 great features. All committed individually + landed on origin/main.

- **R22.28** `f277293` — Bias overrides drag-and-drop import. Parallels
  R17.06 (themes) + R18.09 (MIDI bundles). Drop a .json bias-overrides
  file anywhere on the chip rail / Export-Import row and the existing
  R21.23 import path takes over (same window.confirm merge-vs-replace
  prompt, same toast feedback). Refactored R21.23 file-picker body into
  shared parseAndApplyBiasImport(fileOrText) so both entry points walk
  the same parse + confirm + merge + persist sequence (no behavioural
  drift between click-Import and drop). First-file-only convention
  (bias overrides are 3 chips total; multi-file would invite per-chip
  resolution ambiguity).
- **R22.30** `cfed5ef` — Hotkey conflict toast includes an UNDO action.
  Graduates R21.25's read-only warning toast with a one-click rollback.
  New optional `action` arg on showToast(msg, icon, action?) — pure
  wire extension; existing 2-arg callers unaffected. The undo re-binds
  the displaced hotkey to the OLD bundle by calling setUserPresetHotkey
  with (conflict.id, hotkey) — the lib's 1-binding-per-hotkey invariant
  handles the symmetric strip from the NEW bundle (no new lib code).
  Uses setUserPresets(prev => ...) functional form so a concurrent
  edit between toast-show and Undo-click rolls back against LIVE state.
- **R22.12** `f412fe1` — Camera path touch drag-reorder via long-press.
  Graduates R17.07's HTML5 native DnD (desktop-only). Touch users get
  350ms long-press to grab + 10ms haptic vibration + touchmove
  hit-tests against per-row getBoundingClientRect via the new pure
  `resolveTouchTargetIdx(y, ranges)` helper. Slop guard
  (LONG_PRESS_SLOP_PX=8) cancels the timer if the user scrolled away.
  Multi-touch bails so we don't fight browser pinch-zoom. Half-open
  [top, bottom) intervals; overflow above first row snaps to first
  idx; corrupt range items skip silently so transient layout glitches
  don't lose the gesture.
- **R22.27** `5a9598d` — Per-attractor clamp meter user-tunable warn
  threshold. Graduates R21.22's hard-coded `prox < 0.25 = amber`
  cutoff. Long-press (≥400ms) any clamp meter to open a popover with
  a slider [5%..45%] + reset button. Persisted to localStorage,
  applies to every meter globally. New `classifyClampProximity`
  helper returns 'danger'/'warn'/'safe' tier — atRail trumps every
  threshold (structural, not taste); non-finite prox → 'safe'
  (max-safe first-paint). Constants invariants pinned: MIN < DEFAULT
  < MAX < 0.5 (MAX < 0.5 so green tier always covers middle half of
  slider). New ClampThresholdPopover leaf with backdrop click-outside
  + Escape dismiss + reset-disabled-at-default. Cyan "edited" pip
  appears when threshold is non-default.
- **R22.29** `faac257` — Thumb detail panel editable per-tile note
  field. Graduates R20.19's read-only metadata panel with a free-form
  text input — label thumbnails "good demo shot" / "wrong colors"
  / "use for OG card" etc. Persists alongside metadata in the same
  envelope (no schema rev; note field is optional, forwards/backwards
  compat). New THUMB_NOTE_MAX_LEN=240 cap. New setThumbNote atomic
  helper: reads existing JSON, merges just the note key, writes back
  — preserves capturedAt + every other field so a note edit never
  resets thumb age. Empty/whitespace/null REMOVES the note key
  (clean schema). Ref-equal-on-no-op contract. ThumbNoteEditor leaf
  with read-only italic amber preview / dashed "+ Add note" empty
  state. Edit mode autofocused 3-row textarea + Save/Cancel/Clear
  + char counter (amber within 20 of cap, red at cap). Enter saves,
  Shift+Enter newline, Esc cancels, blur saves silently.
