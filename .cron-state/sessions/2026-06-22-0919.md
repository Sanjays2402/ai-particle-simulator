## Key decisions

1. **R18.16 band-hysteresis design.** Chose a symmetric ±0.015 dead-band around each band boundary (so total 0.03-wide hold zone) — narrow enough that a steady knob sweep still hits every type, wide enough to absorb micro-jitter from a noisy MIDI controller. The dead-band ONLY holds when the previous type is an immediate neighbour of the target band, so a sudden knob slam from attractor → vortex (skipping repulsor) snaps cleanly to the new band. Mirrors the spirit of R15.16's Schmitt-trigger ENABLED routing but adapts the shape for an N-way cycle instead of a 2-way toggle.

2. **R18.09 single-vs-multi auto-detect.** parseImportMulti is a strict shape match (kind=midi-user-bundles + bundles array, OR bare array shorthand) so it cleanly rejects single-bundle envelopes; we try it first then fall through to parseImport. No new IO module needed — pure wire layer in MidiPanel + a presentational drop-zone wrapper in PresetBar.

3. **R18.18 partial-success semantics.** With N files dropped, parsing them in parallel via Promise.all and combining valid items into one preview means a single malformed file can't kill the whole drop. Filename-sorted ordering keeps the merged preview deterministic across machines. Sources list threaded through the existing pendingPack state without breaking the file-picker path.

4. **R18.19 grab-handle UX.** Three layered controls now cover the reorder space: chevrons (R15.20 — precise single-step + keyboard a11y), badge click-to-edit numeric jump (R16.18 — arbitrary position), and badge drag (R18.19 — direct visual move). draggable={!!onDragStart && !editing && !editingPos} so text edits aren't interrupted.

5. **R18.06 long-press over keyboard modifier.** Picked long-press (parallels mobile patterns in Photos / Files / Gmail) instead of shift-click (which named-attractor multi-select uses) because grid view's primary tap target is the lightbox; making shift-click the multi-select gesture there would break the one-handed "tap to view" flow. Long-press + tap-toggle keeps both modes orthogonal: tap-at-rest opens lightbox, tap-in-select-mode toggles. Selection auto-clears on view-change so the strip view never grows multi-select UI.
