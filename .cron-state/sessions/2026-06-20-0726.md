   (preset, palette, FX, force field, audio mode, camera modulators) to
   localStorage. B quick-saves, Shift+B restores most recent. 12 cap,

   bookmarks.
3. **R3.03 Slideshow** (bd78841) — Auto-cycle through the preset
   library. Three orders: sequence, shuffle (avoids current with
   bounded retries), favourites (chip disabled when no favs starred).
   Dwell 2-60s in the UI, store clamps to 2-120 so kiosk bookmarks
   can carry longer values. Manual loads reset the timer.
4. **R3.04 Crossfade** (22e4091) — Lerp between current preset and a
   chosen target using smoothstep eased progress over 0.5-10s. When
   complete, target becomes the new current preset. Allocation-free
   blend path (two reused scratch vectors). Plays nicely with
   kaleidoscope, audio, palette, hue cycle.
5. **R3.05 Reduced motion** (9e4239f) — OS-aware accessibility mode
   (prefers-reduced-motion media query) with auto / reduce / full
   override. Gates hue cycle, auto-rotate, camera shake, parallax
   orbs, and splash boot animation. Settings → Accessibility shows
   the current effective state.

## Architecture decisions worth remembering
- Scene bookmarks use a SCENE_FIELDS whitelist (not a blanket copy)
  so we don't accidentally serialize particleFn (a JS closure that
  would crash JSON.stringify) or aiApiKey (a credential the user
  doesn't want round-tripping through a bookmark file).
- Background gradient achieves "zero per-frame WebGL cost" by flipping
  alpha:true on the canvas and painting CSS underneath instead of
  adding a Three.js plane. Particles still render on top via z-index.
- Crossfade uses smoothstep (3t²−2t³) on the progress value before the
  lerp so the ramp eases at both ends — pure linear was abrupt.
- Reduced motion uses a `resolveReducedMotion(userMode, osPref)` truth
  table so the UI override always wins ('reduce' or 'full' beat the
  OS pref). 'auto' defers, unknown defers. No silent surprises.
- For App.jsx splash skip under reduced motion: read the OS pref +
  localStorage override at useState init time, NOT in a useEffect.
  Calling setState synchronously inside an effect trips the
  cascading-renders lint and wastes a render cycle.

## Bookmarking-style features that compose
We now have THREE persistence surfaces in localStorage:
- `particle-camera-views-v1`   — orbit camera state (6 max)
- `particle-snapshot-gallery-v1` — PNG thumbnails (8 max)
- `particle-scene-bookmarks-v1` — full scene config (12 max)
Each uses the same `{ v: 1, items: [...] }` shape so a future
"Export all" / "Import all" panel could batch them.
