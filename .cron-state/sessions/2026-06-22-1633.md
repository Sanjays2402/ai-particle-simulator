## Lessons / observations

- The "eslint-disable-next-line no-unused-vars" pattern I reached for
  to silence the underscore-prefixed destructured locals doesn't
  actually trigger because the repo's eslint config doesn't enforce
  no-unused-vars on `_`-prefixed names. Surfaced as "Unused
  eslint-disable directive" warnings at the gate. Switched to
  explicit `Object.keys(...).filter(...)` loops — clearer intent,
  no eslint dance, easier to read in 6 months.
- The R20.11 global keydown listener referenced `map`/`setMap` (a
  stale draft) but the component actually uses `bindings`/
  `setBindings`. Lint caught it at the end-of-batch gate. Reminder:
  always grep for the state names being threaded through new
  effects, even when "the code looks right at a glance".
- R20.16's first proximityToBoundary01 implementation treated v=0
  and v=1 as boundaries (returned 0 proximity). The first test
  catch surfaced it — edge bands only have ONE real boundary, the
  other "edge" is the range endpoint where the knob can rest safely.
  Fixed by tracking hasLeftBoundary / hasRightBoundary explicitly
  in the projector.
