## Architecture notes

- Every feature uses the same pattern: an opt-in toggle in the
  LeftSidebar that gates the renderer cost (zero or near-zero work
  when the toggle is off). Lets users layer features without burning
  framerate.
- Reduced-motion accessibility mode now gates **two more** features
  (wind drift and noise wiggle), in addition to the things it
  already suppressed (auto-rotate, hue cycle, camera shake, splash
  fade, orb parallax).
- The custom theme path required threading `customThemes` into the
  per-frame canvas via `resolveTheme(themeId, builtins, customs)`.
  Built-in keys still win on collisions so a sneaky / corrupted
  custom row can never override `neon`/`cyberpunk`/etc.
- Touch gestures are kept stateless in `lib/touchGestures.js` (pure
  math) with the state machine in `useTouchGestures.js` (the
  React-flavoured layer). Lets the math be unit-tested without a DOM.
