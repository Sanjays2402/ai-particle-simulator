## Design notes

- Every IO module added (crossfadeOverridesIO) follows the exact same
  envelope shape, version gating, merge/replace API, and
  sanitize-on-load contract as the existing wind / themes / bookmarks
  IO. The five preview/IO modules now in the app form a coherent
  family — easier for users to learn, easier for me to maintain.
- The keymap diff preview replaces a `window.confirm()` call that
  asked users to remember which button meant which mode. Major UX
  win for a small amount of code.
- Per-attractor MIDI x/y/z setters intentionally read the LIVE
  position triple at apply-time rather than closing over a snapshot.
  This is the right call for concurrent multi-axis sweeps (a regular
  use case for performers with multiple faders bound at once). The
  concurrent-axis preserve regression test will catch any future
  refactor that breaks this.
- User-bundle editor is opt-in — the "Your Bundles" section stays
  hidden until the user clicks "+ Save current as bundle" or has at
  least one saved. Out-of-box the MIDI panel looks identical to
  before.
