## Trade-offs / notes

- R2.02 (Echo / trail FBO that survives EffectComposer) was originally
  next in Batch 2 but it's a render-pipeline refactor — replacing the
  current `gl.autoClear=false` trail hack with an FBO ping-pong rig
  needs its own shader + composer pass and is too risky to attempt as
  one slice of five. Swapped in R2.06 (session stats) instead and
  moved R2.02 to the deferred queue (R3.15) for a future dedicated
  batch.
- Audio teardown is now centralised in `teardownAudio()` so both mic
  and demo loops use the same cleanup. Switching between sources
  destroys the prior context to avoid stacking.
- The snapshot gallery is hard-capped at 8 entries with a 1.5MB-per-PNG
  ceiling. On quota throw we retry once with PNGs stripped so the
  thumbnails always survive (visible via a "thumb" badge on the tile).
- The code viewer is read-only this tick; making it editable + recompile
  is queued as R3.16.
