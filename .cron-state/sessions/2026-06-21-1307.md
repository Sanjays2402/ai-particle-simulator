## Architectural notes for future ticks

- **Curve presets pattern reusable**: `shapeReactiveSignal(s, curveId)` is a generic 0..1 → 0..1 reshaper. Crossfade smoothstep is a fixed cubic; if R13 ever wants user-pickable crossfade curves, this is the exact mechanism — just expose REACTIVE_CURVES (or a parallel) and call it before the lerp.
- **Bias profile pattern reusable**: SCENE_BIASES is just data — same shape would work for randomising preset parameters, randomising audio mappings, etc. The injected RNG keeps it pure + testable.
- **Attractor action namespace**: `attr:<id>:<field>` is structured. If R13.18 adds RADIUS / X / Y / Z routing, just add fields to ATTRACTOR_FIELD_* constants and resolveActionForId; nothing else needs to know.
- **Wind override IO mirrors customThemesIO**: future "export your tweaks" features (crossfade overrides R13.14, keymap remap, MIDI bundle editor R13.05) should copy the same envelope shape so users get a consistent JSON pack workflow.
- **PinchZoom keyboard pan is generic**: same helpers could drive any zoomable surface — preset thumbnail browser, future inline timeline scrubber, etc.
