- R19.12's `log` curve formula upgraded from `sqrt(t)` to `log(1+(base-1)*t)/log(base)`
  with default base=4. The endpoint anchors (0→0, 1→1) stay invariant; the inner
  shape is slightly less aggressive than sqrt at midpoint (0.404 vs 0.5) but still
  solidly tail-leading vs linear. Updated R16.17's `near(applyTrailCurve(0.25,'log'),0.5)`
  test to assert against the new formula explicitly + added an independent
  `applyTrailCurve(0.25,'log') > 0.25` invariant so the "tail-leading" semantic
  remains pinned.

  setState + same-value-skip + bound-CC-only filter. Same observable behaviour,
  just a proper React signal that lint accepts.

  gap div + main row div). LSP TS server flagged a false-positive about `</>`;
