## Architecture notes

- The **keymap** layer was applied across 3 components in one swoop
  (TopBar dispatcher, RightSidebar camera-views + bookmarks, Help
  overlay). All three lost their literal `e.key === 'b'` checks and
  gained a uniform `resolveAction(loadKeymap(), e)` call. Touch-
  gestures and digit shortcuts intentionally stayed hard-coded for
  now — they're not "rebindable" in any useful sense.
- **MIDI** uses two layers: an interactive panel for setup, and a
  separate `useGlobalMidi()` hook that only requests `MIDIAccess` if
  the user already has saved bindings. Keeps no-controller users
  from ever seeing a permission prompt.
- The **editable viewer** dispatches through `loadCustomCode()` — the
  same code path the AI flow and Smart Text Engine already use — so
  the new fn just becomes the live particle fn with no extra
  plumbing. The `(edited)` suffix in the info panel lets users tell
  at a glance the live scene came from their edits, not a preset.
- **Waveform** lib is genuinely pure — `bytesToCentered` /
  `peakAmplitude` / `projectToCanvas` / `sampleAnalyser` can all be
  unit-tested with a fake analyser that fills bytes from a closure.
  This was the easiest test file to write all batch.
