## Process notes

- The keymap IO feature reused the established envelope pattern
  (kind + v + exportedAt + payload) from bookmarksIO and customThemesIO
  so the parser surface stays familiar. Merge vs replace mode picked
  via a confirm() dialog inline — fits the existing Settings modal
  UX (no extra panel needed).
- Waveform spectrum mode reuses the same canvas, scratch-buffer
  contract, and overlay shell — only the inner render branch swaps.
  Mode toggle is a single chip inside the overlay's top-left corner,
  pointer-events:auto on the chip while the rest of the overlay
  stays pass-through. Persisted under its own localStorage key so
  the on/off toggle and the mode preference are independent.
- Mobile gesture hint listens for a new 'particle:touch-gesture'
  CustomEvent so it doesn't have to re-implement touchstart parsing
  — the existing useTouchGestures hook now dispatches once per
  pinch (first-frame guard) and once per swipe (already cooldown-
  gated). Auto-dismisses 800ms after both gestures are demonstrated,
  giving the user the "both lit green" feedback frame.
- Custom theme boot resolver fixes a long-standing silent bug: when
  a custom theme was persisted as active, the CSS variable for the
  accent never got written on reload because the persistence spread
  bypassed the setTheme side-effect. Boot resolver also handles
  deleted custom themes — flips to the configured default and
  cleans up the stale persistence.
- Named attractors integrate cleanly with the existing physics path:
  one pre-filter pass at the top of the per-frame loop flattens the
  active list to typed arrays of [type, str, x, y, z, radiusSq], so
  the per-particle inner loop only walks the active set with cheap
  squared-distance gates. physicsActive flips on for ANY enabled
  attractor, so a user can run a scene with named attractors as the
  only physics (no need to also enable the legacy single field).
- Pointer-up handler now routes the click to legacy place-field mode
  OR the named-attractor placing slot, with legacy winning if both
  are armed (defensive — the UI doesn't let this happen).
