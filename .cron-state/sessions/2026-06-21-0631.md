     key handling moved from gallery container into lightbox so it can
     read zoom state. Backdrop-click-to-close swallowed while zoomed.
     touchAction: 'none' on stage to disable browser-native gestures.
     Zoom resets when displayed snapshot changes.

     writing `zoomRef.current = zoom` during render → moved to effect;
     react-hooks/set-state-in-effect for the reset → wrapped in
     queueMicrotask per the precedent already in RightSidebar).
   - Tests: 50+ asserts covering clamp/distance/midpoint, bounds at
     every scale, idle→pinch→update→end transitions, centroid follow,
     boundary stretching, double-tap geometry (centered + corner +
     reset), wheel intent, transform string, nav gate.

     returns false, null/empty/non-string-id defensive).

   - store.js: spectrumPeakHolds + setSpectrumPeakHolds, persisted to

   - WaveformOverlay.jsx: new `pk` chip next to lin/log when in

   - Note: typo'd email on first commit (Sanjays2402+@) → amended

   - Tests: ~50 fresh asserts — typed-array sizing incl. NaN/negative,
